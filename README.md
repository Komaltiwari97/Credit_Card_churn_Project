# Credit Card Customer Churn Analysis

## Project Overview
This project focuses on analysing customer churn in the credit card industry using data analytics techniques.

The main objective is to understand customer behaviour, identify churn patterns, and discover factors associated with customer churn.

## Dataset Information
- Total Records: 100,000
- Total Columns: 40
- Missing Values: 0
- Duplicate Records: 0
- Target Variable: churned
